## Project Overview
This project is being developed for hackathon #2 and is inspired by Kate Crawford and Vladan Joler's [Calculating Empires](https://calculatingempires.net/).

Our goal is to create an original, interactive c++ application exploring the relationship between technology, society, and the concepts of abstraction, efficiency, or recursion.

**Project Title:**
FlockWatch

**Project Description:** 
For this project, we will be using a map that includes the CCNY campus and its surroundings. Flock cameras, cameras that photograph passing vehicles and log searchable records of where or when they travel, are going to be placed around the map. Cars will also be placed around the map ready to be captured by the Flock cameras.
